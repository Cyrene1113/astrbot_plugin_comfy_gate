# astrbot_plugin_comfy_gate

ComfyUI 出图闸门 —— 把 comfyui-pipeline skill 的固定流程封装成单个 LLM 工具。
作者：昔涟

## 能力

- 群友在群里用**自然语言**点单（如「画一张少女在花田里的图」），自动走固定流程出图。
- 私聊（**非群聊一律按私聊处理**）里**管理员**可指定工作流精细出图（说工作流名关键词即可，实时匹配目录，找不到会返回候选清单）；非管理员的调用不执行任何操作（返回中性 noop，由 LLM 自然继续对话）。
- 工具名：`comfyui_render`
- 参数（全部可选，仅 `prompt` 必填）：
  - `prompt`：画面描述（正向提示词）
  - `workflow`：工作流名关键词，仅私聊管理员生效；不传则沿用本会话上次的工作流（首次用默认工作流）
  - `negative`：负面提示词，默认沿用工作流自带负面词

## 设计约束

1. **自然语言调动，只跑固定流程**：探活 → 复制基准到临时文件 → 改提示词 → 提交 → 出图 → 删临时文件，全自动，不暴露节点细节。
2. **指定工作流**：只从固定工作流目录按文件名**实时模糊匹配**，别名、默认工作流、目录路径全部外置在 `data/workflow_config.json`；工作流改名/增删/挪目录只改配置文件，不动代码；匹配不到时返回实时候选清单。不污染基准文件。
3. **群聊固定快速出图**：群友点单统一走 `fast_workflow`（默认快速出图版），轻量娱乐向。
4. **非群聊仅管理员**：非管理员的调用直接返回中性 noop，插件不执行任何操作、不发消息，由 LLM 按 docstring 约定自然继续原对话。
5. **权限隔离**：不调用 shell / python 工具，全局管理员限制不受影响；本工具走非内置工具的 `tool_permissions` 表，默认 member 即可用。

## 配置

`data/workflow_config.json`（缺项用内置默认补齐，改文件即热生效，无需改代码）：

- `workflow_dir`：工作流目录绝对路径
- `skill_scripts_dir`：comfyui-pipeline skill 脚本目录（目录缺失时插件加载失败并给出明确提示）
- `fast_workflow`：群聊固定使用的工作流名关键词（按目录实时模糊匹配）
- `private_default`：私聊会话粘性为空时的默认工作流名关键词
- `max_concurrent`：全局同时出图上限（默认 2，含管理员）
- `cooldown_seconds`：每会话出图冷却秒数（默认 30，仅对非管理员生效，管理员免冷却）
- `aliases`：可选的「口语名 → 目标文件名子串」映射，仅当口语名不是任何工作流文件名的子串时才需要配；可空

## 安装

把本目录放到 `data/plugins/` 下，在 AstrBot WebUI 重载插件即可。
工具注册名 `comfyui_render`，属于非内置工具，默认所有成员可用；如需收紧，可在
WebUI → 扩展 → 组件 的工具权限里对该工具单独配置。

## 输出

成图保存在会话工作区 `comfy_out/`。出图完成后由插件在后台把图片**直接推送到当前会话**，同时向对话上下文注入「已交付」提示（含本次工作流名），LLM 只负责文字回应，禁止重复发图；私聊管理员出图延续会话粘性工作流。
